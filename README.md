# Holiday-Statistics-Calendar

A simple static calendar for tracking when each group member is on holiday.

## Use

Open `index.html` in a browser, add a name and a start/end date, and manage entries with the edit and delete buttons. Calendar entries are stored in that browser's `localStorage`, so they remain after a refresh and update across tabs on the same origin.

Because this is a static site without a shared backend, data is not synchronized between different users or devices. To share one common schedule across devices, the site would need a shared data service.
